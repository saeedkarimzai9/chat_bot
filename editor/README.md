# System Edit 🎬

A free, locally-focused CapCut-inspired video editor prototype.

## Current prototype
- Dark professional editing workspace
- Media import and video preview
- Timeline with video/text/audio tracks
- Text and emoji/sticker tools
- Effects, filters, transitions and captions panels
- Basic playback controls

## Roadmap
1. Electron desktop shell
2. FFmpeg import/export
3. Real timeline trimming/splitting
4. Keyframes and animations
5. Audio waveform and recording
6. Caption generation
7. Effect/filter engine
8. Templates and project files
9. Windows installer

The project uses original branding and UI assets rather than copying CapCut's proprietary assets.
