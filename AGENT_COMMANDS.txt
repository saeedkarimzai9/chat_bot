WORKFLOW
1. Tell ChatBot what you want in normal language.
2. For supported file commands, the desktop agent prepares the file.
3. A visible Windows Command Prompt asks for Y/N confirmation.
4. Press Y to create the file or N to cancel.
5. Created files are stored in your ChatBotAgentWorkspace folder.

The agent is intentionally confirmation-gated and does not execute arbitrary shell commands.
